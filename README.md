# my-keeb
My keeb design and documents for the hack club keeb YSWS
TOTAL OF 32 hours learning and building

This YSWS was my first hack club project. I learnt about hackclub from online and I had a great time building and completeing this project. During theis project I made a custom keyboard with programmable macro keys and learnt 3d onshape design, soldering,kicad pcb design and also about different styles layouts and mounts of keyboards.My finished project was one that i am proud of and here it is!
